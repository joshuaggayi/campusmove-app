# CampusMove (Flutter)

Android app that helps Kampala university students plan public transport journeys:
compare taxi and boda boda options by fare and time, follow stages and landmarks, and
read or write community reviews. All data is stored on the phone (SQLite), so it works
offline and needs no server.

## Screens (match the Task 1 report)

| Functionality | Files |
| --- | --- |
| 1. Sign-up / Login (name, email, password, role) | `lib/screens/login_screen.dart` |
| 2. Route navigation (search, compare, stages) | `home_screen.dart`, `results_screen.dart`, `route_detail_screen.dart` |
| 3. Feedback and reviews (1-5 stars, comment, admin moderation) | `review_form.dart`, `reviews_screen.dart` |
| Extras | `saved_screen.dart`, `profile_screen.dart`, `main_shell.dart` (bottom navigation) |

## Run it

This folder holds the Dart code and `pubspec.yaml`. The Android platform folder is
generated by Flutter on your machine:

```bash
cd campusmove
flutter create . --project-name campusmove --org ug.ac.mubs --platforms=android
flutter pub get
flutter run                      # phone or emulator
flutter build apk --release      # the .apk to submit
```

The release file is `build/app/outputs/flutter-apk/app-release.apk`.

If `flutter create` adds `test/widget_test.dart` and the analyzer complains about it,
delete that file.

illustrative. Replace them with figures from your own field survey before the demo.
Each route is stored in both directions automatically.

## Notes

- Passwords are stored as SHA-256 hashes (with a fixed app salt). That is fine for
  coursework; a real app would use a server and per-user salts.
- To reset the data, uninstall the app (or clear its storage) and reinstall.
